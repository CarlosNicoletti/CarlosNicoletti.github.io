# 🌐 Portfólio pessoal

Meu site pessoal, feito do zero com **HTML**, **CSS** e **JavaScript** puros, sem frameworks.

🔗 **Acesse:** https://carlosnicoletti.github.io

## ✨ Funcionalidades
- **Responsivo:** se adapta a celular, tablet e computador
- **Tema claro e escuro:** a escolha fica salva no navegador (`localStorage`)
- **Menu "hambúrguer"** no celular
- **Efeito de digitação** no título
- **Animação ao rolar** a página (`IntersectionObserver`)

## 🗂️ Estrutura
```
├── index.html   → estrutura e conteúdo da página
├── style.css    → aparência (cores, layout, responsividade)
└── script.js    → interações (tema, menu, digitação, animações)
```

## 📚 O que aprendi
- Organizar uma página com tags semânticas (`header`, `main`, `section`, `footer`)
- Usar variáveis CSS para criar temas
- Layout com **Flexbox** e **Grid**
- Media queries para telas pequenas
- Manipular o DOM e eventos com JavaScript
- Publicar um site de graça com o **GitHub Pages**
